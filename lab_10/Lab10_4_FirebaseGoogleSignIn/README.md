# Lab10_4_FirebaseGoogleSignIn

## Mô tả
Ứng dụng đăng nhập với tài khoản Google (Google Sign-In / Firebase Authentication).

## Cách chạy ứng dụng
```bash
flutter pub get
flutter run
```
*Lưu ý: Để chạy thực tế trên thiết bị Android, cần gắn file `google-services.json` từ Firebase Console và cấu hình mã SHA-1.*
